# DownloadSweeper Windows 便携版

1. 将整个 ZIP 解压到可写的独立文件夹。
2. 双击 `Start.cmd`，浏览器会打开本地整理工作台。关闭服务窗口可停止程序。
3. 在“模型与设置”选择服务商并填写自己的密钥，自动获取账号模型名单；选择模型后自动带入已知上下文和视觉能力，保存后可测试连接。也可复制 `.env.example` 为 `.env` 并填写 `DS_API_KEY`，重启后读取。可以先体验不需要密钥的本地规则整理。

网页界面已嵌入 `ds-web.exe`，运行时不需要 Rust、Node.js 或额外的 frontend 目录。

首页提供“下载目录整理”“桌面整理”和“文件名重生”。桌面模式只扫描第一层，快捷方式保留原位并在桌面文件列表中隐藏 .url/.lnk；已有文件夹允许按权限识别和整体移动，内部不能拆散；同时提供完整六步流程：扫描、权限、目标树、Agent 规划、审查、执行。可编辑多层分类、备注与文件示例，调用 Agent 生成树建议、读取授权内容并批量分类，查看工具轨迹和费用，暂停后继续。已有文件夹可在节点参数中标记为“复用容器”，再映射到目标树一级分类：只接收新文件，原内容不扫描、不拆散。需要整理其内部文件时，使用下载目录整理模式。

桌面默认模板已包含可供 AI 分类的复杂规则子目录。规划页显示可处理文件数与跳过原因；旧任务若显示“缺少复杂规则子目录”，请返回目标结构补充子目录，或生成并合并 AI 目录建议。零候选不会调用 API，也不会显示为 AI 规划成功。

权限页提供 14 类彩色命名预设，具体扩展名可编辑，修改后保存；规则按编号优先匹配，支持调整顺序。类别名仅用于显示，实际授权由扩展名、大小和读取权限决定。目录预览缩小为辅助区域，可按需全屏。

目标画布中，拖动孤立节点标题可移动整棵子树；新建和断开的节点均适用。子节点相对位置保持不变，松开后保存坐标，重新连接主树后自动排列。

整理完成后可在“文件删除建议”中勾选并确认移入系统回收站，再按批“一键撤销”。只有人工确认才会回收，AI 不会自动删除。回收站内按 DownloadSweeper-Recycle 标识分组，内部保留原文件名；保留本机任务数据才能自动还原原路径。恢复遇到同名文件会停止，回收站被清空后无法撤销。详细边界见 ARCHIVES_AND_CLEANUP.md。
模型协议、能力来源与密钥工作流详见包内 `MODEL_CONNECTIONS.md`；并行、预算与检查点说明见 `AGENT_RUNTIME.md`，自动和手动计费见 `PRICING.md`。
Windows 版本使用系统安装的 Microsoft Visual C++ 运行库；若启动时提示缺少
`VCRUNTIME140.dll`，请安装与包架构匹配的 [Microsoft Visual C++ v14 运行库](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist)。
`Start.cmd` 会在首次启动时将示例配置复制为 `config.toml`；之后保留已有配置。
配置、任务历史与恢复日志保存在此文件夹的 `config.toml` 和 `.ds-data` 中。
保留这些文件才能继续原来的任务和恢复操作；分享程序时使用原始发布 ZIP。

`.env` 与 `config.toml` 位于同一目录，属于本机明文凭据文件，不可分享。也可以从启动终端或系统环境提供 `DS_API_KEY`；已有进程环境变量优先于 `.env`。显式 `api_key_env` 只读取其指定变量，不回退到其他密钥；未指定时兼容 `DS_API_KEY`、`OPENAI_API_KEY`、旧版内联 `api_key`；可选搜索使用 `DS_SEARCH_API_KEY`。空示例适用于本地无鉴权服务。

设置页的新密钥保存到私有 `.env`，`config.toml` 仅保留变量名；查询列表不保存密钥。列表不可用时会提供尚未验证权限的官方预设，未知能力需要手动填写。支持 OpenAI Chat Completions、Responses 和 Claude 原生 Messages。构建脚本会检查发布目录和 ZIP 中的凭据；请勿转发使用后包含 `.env`、个人配置或 `.ds-data` 的整个文件夹。开发者可在源码目录运行 `python scripts/verify_share.py --package <ZIP路径>` 重新验证交付物。

本版对新移动使用 BLAKE3 指纹：不超过 1 MiB 的文件完整读取；超过 1 MiB 时，
在首尾及中间三处各读取 64 KiB，共 320 KiB，并核对文件大小与修改时间。目录内部文件分别处理。
抽样不能保证发现未覆盖区域的修改。旧分段 v1 记录保留 16 MiB 门槛，旧 BLAKE3 全量和 SHA-256 记录仍按原算法完整校验。
校验期间显示实际读取量。升级前先等待正在执行的任务结束，
再关闭服务并替换程序，保留原来的配置和 `.ds-data`。请使用本版或更新版本恢复本版创建的操作。

默认访问地址为 `http://127.0.0.1:3187`。若该端口已被占用，可在终端执行
`Start.cmd --port 3188`。同一份任务数据只允许一个服务进程打开。

图片缩略图和 Windows 系统原生视频抽帧已包含在程序中，无需安装 FFmpeg。
系统不支持的视频编码可选用 FFmpeg 后备；仅按文件名整理不需要解码器。

如果包内包含 `ds.exe`，可执行 `ds.exe help` 查看 CLI 用法。CLI 与网页共享此文件夹中的任务数据，使用时先停止网页服务，并在此文件夹中打开终端。

多模态与 Office 预览说明见包内 MULTIMODAL.md。Office 文本无需安装附加软件；视频优先使用 Windows 原生解码，可选使用本机 ffmpeg/ffprobe 后备，设置页显示后端状态。解码不可用时仍可使用已授权的文件信息。

规则页可添加“文件夹”（@folder）预设；目录摘要与内部文件同时受文件夹和逐格式权限约束。AI 可建议新增缺失的一级格式目录。建议需手动勾选合并；取消父级建议时，依赖的子孙建议取消勾选并置灰。

AI 重复新增默认模板中的同名节点（如“照片”）时，Rust 会复用同父目录下规则兼容的原节点并修正子节点引用，保留已有文件示例、映射和画布位置；实际修改仍需审查合并，不会额外请求模型修复。

审查页提供“告诉 AI，哪里还需要调整”：例如“把视频从其它移出，放进新的视频一级目录”。建议以差异显示，可勾选采纳；应用后自动完成具体位置规划，直接更新“整理后”预览。扩展名分类在本地计算，语义规则变化时只对受影响条目进行受权限约束的 AI 分类，保留其他分类与已取消勾选的操作。完成批次会保存，失败或暂停时原计划保留，继续时复用有效批次。也可通过 AI 浮窗调整指定文件归属或要求保持原位。应用成功后需要重新确认审查，实际文件仍等到最终执行步骤才移动。较大任务只向助手提供有权限的有限文件列表及分类数量，类别规则修改适用于完整计划。

目录画布统一采用父节点在上、子节点横向成行的排列，卡片底部提供紧凑的展开／收起按钮；目标树可通过“＋”新建子目录。自动排列保留折叠状态，孤立节点可带整棵子树拖动。

并行分类显示进行中路数、排队批次和完成批次，以及正在处理的类别和文件数。进度百分比只累计完成的文件；运行中的批次不会被估算为已完成，暂停后继续复用已保存批次。
