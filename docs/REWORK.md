# DownloadSweeper 重构记录

## 需求基线

以本次用户说明及旧对话的用户消息为准。旧代码备份位于项目旁的
`downloadsweeper-before-rework-20260903.zip`。旧对话中浏览器历史数据库写回已明确暂缓。

- Rust 控制所有扫描、权限过滤、AI 编排、规划、执行和恢复；网页仅负责呈现和编辑。
- 同一次任务的 JSON 从扫描开始保存，六阶段依次解锁；上游修改使下游计划失效。
- 实际目录、目标目录和审查对比全部使用 React Flow 节点画布。
- 节点图改为父上子下、子节点横向成行，上父下子端口、卡片底部新建与折叠快捷按钮；保留节点参数、备注、真实文件 few-shot、右键新增、断线孤儿、无环校验。
- 实际目录可拆散 / 整体保护 / 复用容器，变更不重新扫描。
- AI 浮窗支持拖动、折叠和最大化，建议限定当前场景、逐项 diff 审查、显式合并。
- 规则决定一级分类，AI 只在该分支继续细化；权限不足时保留简单分类。
- 进入生成计划阶段时自动运行本地规则，完成后保留 AI 细化和下一步审查入口。审查页也可继续细化；返回规划、AI 失败或取消均保留已有计划，修改上游规则才作废。细化保留操作 ID 和勾选状态，更新结果后重新确认审查。
- AI 分类按同一候选节点集合动态组批，通过原生 `read_file_evidence` / `submit_classifications` 工具完成。数量上限可调，默认 256；上下文、证据和输出预算决定实际批量。已完成批次可续接，模型无法编辑树或直接操作文件。工具 Markdown 说明直接用于运行时提示。
- 审查建议应用后自动完成受影响条目的具体位置规划，完成前保留旧树与旧计划；按内容细分仍遵守权限、并发和预算限制。完成批次持久化，成功后统一发布到“整理后”预览，不在反馈区重复显示目标树，也不提前移动文件。
- 所有真实操作都经过计划审查；不覆盖、不主动清理文件，追加日志和可恢复执行记录。
- SSE 进度、取消、持久化任务历史、JSON 导入导出、逐调用用量与预算。

## 初始检查

- 项目没有 Git 仓库，已单独备份原始源码。
- 当前 UI 绑定 Tauri IPC，无法独立使用浏览器。
- Windows 的 cargo/rustup 启动链接不可执行；现有 stable 工具链直接调用可用。
- 初始 engine 单元测试 33 项通过；分类集成测试 `hybrid_rule_cache_llm` 失败。
- 树层级在默认模板与校验中的定义不一致，多个同扩展名一级分类互相冲突。

## 新架构

`engine/workflow`：任务模型、状态转移、图校验、扫描快照和规划。
`engine/workflow_ai`：权限过滤后的上下文、AI 建议和分类、用量记录。
`engine/safe_fs`：文件版本检查、无覆盖移动、预写日志和恢复。
`web`：127.0.0.1 HTTP / SSE、同源校验、任务互斥与静态资源。
`frontend`：React + React Flow，无远程 CDN、无前端构建步骤。

## 交付验证

- Windows 浏览器、CLI、Tauri 三个入口编译通过。
- 旧有 57 项 Rust 测试保留通过，新增 20 项 workflow 测试，合计 77 项。
- HTTP 集成覆盖真实文件夹夹具、六阶段门控、隐私、场景差异合并、AI 分类、搜索辅助命名、AI 清理复核、精确 usage/cost、SSE 与取消、预算与缺失用量拒绝、执行恢复哈希一致、会话导入、Origin/Host/token 防护。
- 独立 CLI 集成测试通过创建、阶段推进、计划、批准、执行、恢复和 JSON 导入导出。
- 浏览器人工式操作验证连续下一步、AI 最大化/收起与合并、节点内文件示例、拖线换父级、Delete 断线保留孤儿、前后树预览、七项演示文件移动及恢复。
- 模型与搜索只使用本地模拟服务，未向外部模型发送用户文件。未触碰真实下载目录。

新增统一 CLI 适配器，移除旧的命令执行分支；进程锁阻止 CLI 与网页同时写同一数据目录。配置示例修复 token_budget 所在 TOML 层级及价格单位问题。搜索协议参考 Tavily 官方 API 文档，搜索密钥与模型密钥分开配置。

## 已知边界

远程模型密钥缺失，需用户在设置页填写后实测；macOS 尚未实机验证。PDF/Office 正文抽取、HEIC、语音转写暂未实现，权限不足或缺少解析能力时只用允许的信息。浏览器下载历史回写遵循旧对话暂缓决定，不启用。详见 README。
