# 两分钟桌面整理演示

解压演示 ZIP，双击 `Start-Demo.cmd`，浏览器会打开完整工作台和右侧十步导览。无需安装 Rust、Python、Office 或 FFmpeg，无需 API Key。建议窗口宽度至少 1360 像素，提前启动一次以确认本机浏览器和系统回收站工作正常。

**这是功能演示包：模型回答使用本地确定性预设，Token 和价格是模拟值，实际 API 费用为零。扫描、权限过滤、Office/图片/视频/PDF 证据提取、工具协议、并行任务、计划校验、文件移动、系统回收站恢复和操作轨迹使用正式 Rust 引擎。它不能证明真实模型的推理或识别质量，也不能理解任意自然语言指令。**

**固定场景，可反复复现。** 首次启动在 `%LOCALAPPDATA%/DownloadSweeper-Demo/desktop-v1/Desktop` 建立固定的 26 个合成文件；之后启动继续同一份文件、同一任务和同一导览进度，不再生成随机目录。AI 建议、分类与命名例子均为固定预设。文件名参考课程文档、开发开销表、论文、音乐/视频工程素材等桌面场景；没有复制个人文档、照片、成绩、账单或聊天记录。

## 补充功能

在“补充演示 / 自由操作”中：

- **查看实际发给模型的媒体证据**：展示从合成文件真正生成的图片、PDF/视频拼图和文本工具结果，以及观测到的并发路数。它展示读取管线，不声称模拟模型识别了画面。
- **打开可移动 AI 浮窗**：可拖动、收起、最大化。树和审查阶段使用与主线相同的预设建议；其他场景提供说明，不能代替真实 LLM 对任意要求的理解。
- **文件名重生**：创建独立命名任务，将 `a8f3d92c.txt` 根据合成正文标题规划为 `Rust Agent 课程答辩提纲.txt`；其余名称保持。使用原界面审查、执行和恢复。
- **历史、Token 和运行记录**：展示真实保存的任务、对话、工具事件，以及明确标注为模拟的 Token/费用。后台任务运行时可使用暂停按钮；能否继续由正式引擎根据检查点与未确认调用决定，不伪造“任意时刻无损续传”。
- **导出当前任务完整 JSON 归档**：导出任务与轨迹。原生历史页可导入为只读归档；本演示禁用从归档切换到任意真实目录执行。
- **自由编辑节点**：修改扩展名、备注和示例；新建/断开节点；拖动孤立节点；展开收起。当前树只有用户采纳后才影响计划。
- **查看参数**：设置页保留模型参数和价格展示；演示连接固定到本机模拟模型，禁用真实 Key 和外部模型查询，以免演示时误产生费用。正式版支持这些配置。

下载目录整理和不同厂商接入并非本次桌面两分钟主线；请使用正式发布包验证真实 API 的模型差异。

## 重复演示与退出

关闭演示启动器所在终端可结束服务。再次双击 `Start-Demo.cmd` 会继续原场景和进度；不用重新配置、扫描或生成样本。

需要从头讲时，点击右侧 **“重置固定场景 · 从头演示”**。程序会恢复演示中的回收和移动操作，清空这次演示的任务记录、对话、模拟用量与额外生成的空目录，回到相同的 26 个文件和第一步。正在运行任务时，先等待完成或暂停。也可关闭程序后双击 `Reset-Demo.cmd`。

重置只针对受控的合成样本。若手工改写了样本或加入其他文件，程序会保留文件并停止重置，不会强行覆盖。需要保留演示轨迹时，请在重置前导出归档。任务时间、作业标识与机器处理耗时可能不同，固定的文件、建议和目标位置保持一致。

不要在演示目录中放入个人文件。演示中的回收使用真实系统回收站：按主线最后一步或使用重置即可恢复，无需清空回收站。运行数据单独保存在上述固定目录，分享原 ZIP 即可。

## 源码与构建

独立入口位于 `crates/demo`，依赖正式 `ds-engine` 和 `ds-web`，不改变正常程序入口。Rust 负责合成素材、本地模拟模型、受限代理和真实后台；小型 JavaScript 导览调用正式 API。

```powershell
cargo test --locked -p ds-demo
cargo run --locked -p ds-demo
powershell -ExecutionPolicy Bypass -File scripts/package-demo.ps1
```

构建依赖与正式 Windows 项目相同；已编译演示包不需要开发环境。单元测试与正式流程校验均使用 Rust。
