提交当前批次的完整分类结果，供 Rust 校验和保存检查点。完成必要的证据读取后，单独调用此工具；不要在同一回答中同时请求其他工具。一次提交整个 files 数组，不能逐文件提交。

参数：batch_id 必须等于本批 ID；assignments 是数组，每项只包含 file_id、node_id、reason。每个待分类 file_id 恰好出现一次，不得重复、遗漏或加入示例文件。node_id 必须来自本批 selectable=true 的已有节点，或为 null；null 表示证据不足，保留该文件本轮开始时的计划。reason 是最多 80 字符的简短依据。

例如：{"batch_id":"b1","assignments":[{"file_id":"f12","node_id":"n5","reason":"明确的校园活动录像"},{"file_id":"f13","node_id":null,"reason":"文件名含义不明，未获内容权限"}]}。ID 必须使用实际输入，不能照抄示例。

工具严格拒绝树编辑字段、路径、命令、未知节点、越界文件、跨类型归类及不完整结果。accepted 仅代表本批分类已保存，不代表磁盘操作已执行。全部批次成功后，Rust 才将分类合成为可审查计划；实际移动由用户在最后阶段确认，并由 Rust 的可恢复文件操作执行器完成。
